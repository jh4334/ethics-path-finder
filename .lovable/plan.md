
# Ethics Pick (에틱스 픽) - AI 윤리 선택 시뮬레이터

초중등 학생을 위한 AI 윤리 교육용 웹앱으로, 시나리오 기반 선택을 통해 윤리적 판단력을 기르고 결과를 분석합니다.

---

## 🎨 디자인 컨셉
- **다크 모던 테마**: 어두운 배경(네이비/차콜), 포인트 컬러(민트 또는 퍼플)
- **큰 터치 영역**: 모바일/태블릿 친화적 버튼
- **진행률 표시**: 상단 프로그레스 바로 현재 위치 시각화

---

## 📱 학생용 화면 흐름

### 화면 0: 시작 화면
- 앱 로고 및 "오늘 우리는 AI를 '바르게' 쓰는 연습을 합니다" 메시지
- 이름/닉네임 입력 (선택사항)
- 학급 코드 입력 (선택사항 - 교사 대시보드 연동용)

### 화면 1: 사전 진단 (3문항)
- O/X 또는 리커트 1~4 형식
- 예시 문항:
  - "AI가 만든 글을 그대로 제출해도 괜찮다"
  - "개인정보는 꼭 필요한 만큼만 받는 게 좋다"
- 사후 진단과 비교를 위한 기준점 설정

### 화면 2: 시나리오 미션 (6문항)
각 미션별 3지선다 선택:
1. **개인정보 최소수집** - 설문 앱 만들기 상황
2. **동의와 설명** - AI 학습용 데이터 수집 상황
3. **편향/공정성** - 추천 알고리즘 편향 상황
4. **저작권/출처** - AI 생성 이미지 사용 상황
5. **허위정보 검증** - AI 답변 검증 상황
6. **딥페이크/책임** - 합성 영상 공유 상황

**선택 후 피드백 화면**:
- 윤리 점수 표시 (0~2점)
- "왜 이게 더 나은 선택인지" 2줄 피드백
- 대안 제시 1줄
- "다음" 버튼으로 이동

### 화면 3: 사후 진단 (3문항)
- 사전 진단과 동일 문항
- 변화 비교용 (화살표/막대로 변화 시각화)

### 화면 4: 개인 결과 리포트
- **4개 역량 바 차트**: Privacy, Fairness, Transparency, Responsibility
- **사전/사후 변화**: 점수 비교 표시
- **나의 어려웠던 문항 TOP1**: 자동 표시
- **실천 약속 입력**: 한 줄 입력 후 저장

---

## 👩‍🏫 교사용 대시보드

### 학급 통계 화면
- 학급 코드로 접근 (별도 로그인 또는 코드 입력)
- **학급 평균 점수**: 사전/사후 비교 막대 차트
- **문항별 분석**: 6개 미션 정답률 및 선택 분포
- **CSV 다운로드**: 연구대회 증거자료용 내보내기

---

## 💾 데이터 구조 (Lovable Cloud DB)

### 테이블 구성
- **sessions**: 세션ID, 닉네임, 학급코드, 시작시간
- **pre_survey_responses**: 사전 진단 응답
- **mission_responses**: 6개 미션 선택 및 점수
- **post_survey_responses**: 사후 진단 응답
- **pledges**: 실천 약속 저장

---

## 🔧 핵심 기능
- 진행률 표시 (6개 중 몇 번째)
- 선택 즉시 피드백 화면 전환
- 4개 역량별 점수 자동 계산
- 학급 코드로 응답 그룹핑
- CSV 내보내기 (교사용)
