
# 콘텐츠 보강 계획

## 1. 공정성(Fairness) 미션 추가 (2개 → 4개)

현재 공정성 관련 미션이 2개(미션 7, 8)뿐인데, 다른 역량과 균형을 맞추기 위해 2개를 추가합니다.

### 새로운 미션 추가:
- **미션 13: AI 번역의 성별 편향**
  - 상황: AI 번역기가 "의사"는 "he", "간호사"는 "she"로 자동 번역
  - 배움: 언어에도 편향이 숨어있다는 것
  
- **미션 14: 피부색과 AI 인식**
  - 상황: 손 인식 앱이 친구의 어두운 피부색을 잘 인식 못 함
  - 배움: 다양성을 고려하지 않은 AI 학습의 문제점

## 2. 결과 페이지 교육적 요약 추가

각 역량별로 **"이 역량이 왜 중요한지"** 설명과 **개선 팁**을 추가합니다.

### 역량별 설명 데이터:
```
privacy: {
  title: "개인정보 보호",
  description: "디지털 시대에 개인정보는 소중한 자산입니다.",
  lowTip: "정보를 공유하기 전에 '꼭 필요한가?'를 먼저 생각해보세요.",
  highTip: "개인정보 보호 감각이 뛰어나요! 주변 친구들에게도 알려주세요."
}
```

## 3. 피드백에 실제 사례 연결

각 미션의 피드백에 **관련 실제 뉴스/사례**를 추가합니다.

### 예시:
- 딥페이크 미션: "2023년 한국에서 딥페이크 피해 신고가 2배 증가했어요"
- AI 채용 미션: "아마존은 성별 편향 문제로 AI 채용 시스템을 폐기했어요"
- 위치정보 미션: "위치 데이터로 개인의 일상 패턴을 알 수 있어요"

## 4. 온보딩 슬라이드 보강

현재 4개 슬라이드에 **역량별 구체적 예시**를 추가합니다.

### 수정 내용:
- 각 역량 소개에 일상 속 예시 한 줄 추가
- "왜 배워야 하는지" 동기 부여 메시지 강화

## 5. 사전/사후 변화에 해설 추가

결과 페이지에서 O/X 변화뿐 아니라 **각 문항의 정답 해설**을 함께 표시합니다.

### 표시 방식:
- 화살표 옆에 해당 문항의 `explanation` 표시
- 틀렸다가 맞춘 경우 격려 메시지 추가

## 세부 구현 계획

### 1단계: 데이터 보강
- `missions.ts`에 `realCase` 필드 추가 및 미션 2개 추가
- `competencyDescriptions.ts` 새 파일 생성

### 2단계: 피드백 페이지 개선
- 실제 사례 표시 박스 추가
- "알고 계셨나요?" 형태로 흥미 유발

### 3단계: 결과 페이지 개선
- 역량별 점수 아래에 설명 추가
- 사전/사후 변화에 해설 토글 추가

### 4단계: 온보딩 보강
- 슬라이드 텍스트 개선
- 일상 속 예시 추가

## 기술적 세부사항

### Mission 인터페이스 수정:
```typescript
interface Mission {
  // 기존 필드...
  realCase?: string; // 실제 사례 (선택)
}
```

### 새 역량 설명 파일:
```typescript
// src/data/competencyDescriptions.ts
export const competencyDescriptions = {
  privacy: {
    title: "개인정보 보호",
    emoji: "🔒",
    description: "개인정보는 함부로 공유하면 안 되는 소중한 정보예요.",
    importance: "한 번 유출된 정보는 되돌릴 수 없어요.",
    lowScoreTip: "정보 공유 전 '꼭 필요한가?' 먼저 생각하기!",
    highScoreTip: "훌륭해요! 주변 친구들에게도 알려주세요."
  },
  // ... 나머지 역량
}
```

### 결과 페이지 UI 추가:
- 역량 바 클릭 시 상세 설명 펼치기 (Accordion)
- 점수에 따른 맞춤 피드백 표시

이 계획을 통해 교육적 깊이를 높이고, 학생들이 AI 윤리를 더 실감나게 배울 수 있도록 개선합니다.
